========================================
PROJECT OVERVIEW
========================================

- Problem statement: Predict demand accurately based on spatiotemporal features like geohash, weather, timestamp, and road type data in a regression hackathon format.
- Objective: Maximize prediction accuracy.
- Evaluation metric (R²): score = max(0, 100 * R²)

========================================
DATA PREPROCESSING
========================================

- Missing value handling:
  - Numeric (Temperature): Median fill
  - Categorical (Weather, RoadType): Mode fill with a dedicated 'missing' indicator column
- Duplicate handling:
  - Checked for duplicate rows (none found in training data).
- Data type conversions:
  - Converted timestamps from string to separate hour and minute integer columns.
- Timestamp processing:
  - Parsed strings in "HH:MM" format.
  - Extracted hours and minutes.
  - Created 15-minute time slots (0-95 indices).
  - Derived dayofweek, dayofmonth, weekofyear, month, quarter, is_weekend, is_month_start, is_month_end from the 'day' column.

========================================
FEATURE ENGINEERING
========================================

- Timestamp features: hour, minute, time_slot, dayofweek, dayofmonth, weekofyear, month, quarter, is_weekend, is_month_start, is_month_end
- Cyclical features: sin_hour, cos_hour, sin_minute, cos_minute, sin_dayofweek, cos_dayofweek, sin_month, cos_month, sin_time_slot, cos_time_slot
- Geohash decoding: Parsed geohash into continuous latitude and longitude using custom base32 decoding.
- Latitude/Longitude features: lat_lon_interaction, lat_squared, lon_squared, lat_plus_lon, lat_minus_lon, geohash prefixes (length 3, 4, 5).
- KMeans cluster features: KMeans clustering applied on lat/lon coordinates with k=5, 10, 20, 50.
- Frequency encoding: Normalized value counts for RoadType, Weather, geohash, geohash prefixes.
- Target encoding: Out-of-fold target encoding with 5 folds on categorical and interaction features (RoadType_le, Weather_le, geohash_le, geohash_prefix4_le, geo_cluster_10, geo_cluster_20, RoadType_Weather, Hour_RoadType, Hour_Weather, TimeSlot_RoadType) to prevent leakage.
- Aggregation features: 
  - Mean, median, std, min, max target demand for geohash, geohash prefixes, hour, time_slot.
  - Temperature aggregations (count, mean, median, std) for geohash, RoadType, Weather.
  - Geohash interaction target aggregations (geohash x hour, geohash x RoadType).
  - Historical demand statistics derived from Day 48 data mapped to Day 49 test set.
- Interaction features: RoadType_Weather, RoadType_Lanes, Weather_Temp, LargeVeh_Lanes, Landmarks_RoadType, Hour_RoadType, Hour_Weather, Lanes_Landmarks, Hour_Lanes, TimeSlot_RoadType, demand_ratio_gh_hour, demand_ratio_ts_hour.
